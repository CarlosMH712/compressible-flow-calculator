# Deployment guide

## Repository structure

`app.py` and `requirements.txt` must remain in the repository root.

## GitHub

Create a public repository named `compressible-flow-calculator`, then push the complete contents of this folder.

## Streamlit Community Cloud

Use:

- Repository: `CarlosMH712/compressible-flow-calculator`
- Branch: `main`
- Main file path: `app.py`
- Python: `3.12`

Do not upload `.venv`, `.env`, or `.streamlit/secrets.toml`.
